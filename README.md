# SOC Home Lab

Hands-on lab to practice Tier 1 SOC work: log collection, alert triage, and incident documentation using Wazuh SIEM.

## Lab Setup

| Component | Details |
|---|---|
| SIEM | Wazuh v4.14.8 |
| Wazuh server | Ubuntu Server 24.04.5 LTS (VM) |

## Triage Reports

| ID | Title | Summary |
|---|---|---|
| [TR-001](0.3%20Triage%20reports/) | SSH Brute Force | Detected repeated failed SSH logins, analyzed source and pattern, documented findings and recommended actions. |

## Skills Practiced

- Deploying and configuring a SIEM
- Reviewing and triaging security alerts
- Log analysis and pattern recognition
- Writing clear incident reports
